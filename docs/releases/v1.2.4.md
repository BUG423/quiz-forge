# 安知刷题 v1.2.4

本版简化了首页，并让练习设置在同一设备上保持上次的选择。

- 错题按题库查看，可移除单题或清空当前题库；选择“全部题库”时先选择要查看的题库。
- 题型和难度选项随当前题库变化；题库、题型、难度、数量、出题顺序和保命题筛选会在下次打开时恢复。
- 移除首页的顶部统计栏和累计统计，设置入口移至“开始练习”卡片。
- 模拟考试按当前题库、题型和题数组卷，交卷显示分数、答对、答错及跳过题数。
- 增加本地 Excel 转换命令 `npm run convert:banks`，每份源文件生成一份独立的可导入题库。

此公开软件包仅包含演示题，不包含真实业务题库。仓库本地 `data/converted/` 的题库可在设置中单独导入。附件包括已签名 Android APK、PWA 静态包、Excel 导入模板和 SHA256 校验文件。
